CaS (Cleaning as a Service)

Documentație Tehnică

Autori

  • Echipa de Dezvoltare CaS

Abstract

CaS (Cleaning as a Service) este o platformă web modernă pentru managementul serviciilor de curățenie. Sistemul oferă o soluție completă pentru gestionarea programărilor, echipamentelor, angajaților și clienților într-un mod eficient și scalabil. Această documentație descrie arhitectura tehnică, componentele și funcționalitățile sistemului.

Introducere

În era digitală actuală, managementul serviciilor de curățenie necesită soluții software robuste și ușor de utilizat. CaS răspunde acestei nevoi oferind o platformă web completă care permite:

  • Gestionarea eficientă a programărilor și serviciilor
  • Monitorizarea în timp real a echipamentelor și resurselor
  • Managementul angajaților și al programului de lucru
  • Interacțiune simplificată cu clienții
  • Raportare și analiză detaliată

Arhitectură

Frontend

Interfața utilizator este construită folosind tehnologii web standard:

  • HTML5 pentru structură
  • CSS3 pentru stilizare și layout
  • JavaScript vanilla pentru funcționalitate și interactivitate

Arhitectura frontend urmează un model modular, cu fiecare pagină având propriile fișiere JavaScript și CSS dedicate. Codul este organizat în următoarea structură: 

Cas-front/
  ├── js/
  │   ├── auth.js         # Autentificare și management sesiune
  │   ├── appointments.js # Gestionare programări
  │   ├── calendar.js     # Vizualizare calendar
  │   ├── dashboard.js    # Dashboard și statistici
  │   ├── equipment.js    # Management echipamente
  │   ├── locations.js    # Gestionare locații
  │   └── orders.js       # Procesare comenzi
  ├── css/
  │   ├── style.css      # Stiluri globale
  │   ├── auth.css       # Stiluri autentificare
  │   └── dashboard.css  # Stiluri dashboard
  └── html/              # Pagini aplicație

Backend

Serverul este implementat în Node.js și folosește:

  • Express.js pentru rutare și middleware
  • PostgreSQL pentru baza de date
  • JWT pentru autentificare

Structura backend-ului urmează arhitectura MVC: 

src/
  ├── controllers/    # Logica de business
  ├── services/      # Servicii reutilizabile
  ├── repositories/  # Acces la date
  ├── core/          # Funcționalități core
  └── jobs/          # Jobs programate

  • Configurarea sediilor și serviciilor

  • Acces la toate rapoartele și statisticile

Manager

  • Monitorizarea sediului specific
  • Gestionarea comenzilor și programărilor
  • Managementul echipei și al programului
  • Raportare la nivel de sediu

Angajat

  • Vizualizarea și actualizarea sarcinilor
  • Raportarea problemelor
  • Gestionarea transportului
  • Înregistrarea consumului de materiale

Client

  • Programarea serviciilor
  • Urmărirea comenzilor
  • Vizualizarea istoricului
  • Oferirea de feedback

Funcționalități Principale

Autentificare și Securitate

Sistemul folosește JWT (JSON Web Tokens) pentru autentificare și management de sesiune. Implementarea include:

  • Login/Register cu validare
  • Sesiuni persistente cu localStorage/sessionStorage
  • Protecție CSRF și XSS
  • Rate limiting pentru API-uri

Management Programări

Modulul de programări oferă:

  • Calendar interactiv
  • Programări recurente
  • Notificări automate
  • Gestionare conflicte

Monitorizare Echipamente

Sistemul permite:

  • Urmărirea stării în timp real
  • Planificarea mentenanței
  • Alertare automată
  • Istoric intervenții

API și Integrări

Sistemul expune un API RESTful complet documentat pentru integrări externe. Principalele endpoint-uri includ:

Endpoint Metodă Descriere
/api/auth/* POST Autentificare și management utilizatori
/api/appointments/* GET/POST/PUT/DELETE Gestionare programări
/api/equipment/* GET/POST/PUT/DELETE Management echipamente

Monitorizare și Logging

Sistemul implementează logging extensiv pentru:

  • Activitatea utilizatorilor
  • Erori și excepții
  • Performanța sistemului
  • Accesul la API

Logurile sunt stocate în format structurat și pot fi accesate prin interfața de administrare.

Schema Bazei de Date

Tabele Principale

  • users - Utilizatori sistem (ADMIN, MANAGER, EMPLOYEE, CUSTOMER)
  • locations - Sedii/locații spălătorii cu coordonate GPS
  • services - Servicii oferite (covoare, mașini, îmbrăcăminte)
  • equipment - Echipamente cu monitorizare uzură și mentenanță
  • resources - Resurse/consumabile (detergenți, chimicale)
  • inventory - Stocuri per locație cu alerte automate
  • orders - Comenzi cu transport și programare recurentă

Tabele de Legătură

  • service_resources - Resurse necesare per serviciu
  • location_services - Servicii disponibile per locație
  • order_resources - Resurse consumate per comandă

Tabele de Monitorizare

  • weather_conditions - Condiții meteo cu impact asupra operațiunilor
  • equipment_usage_logs - Logs utilizare echipamente
  • maintenance_schedules - Programări mentenanță
  • exception_reports - Rapoarte excepții

Tabele de Notificare

  • notifications - Sistem notificări multi-canal
  • rss_feeds - Fluxuri RSS pentru consultarea stării sediilor
  • inventory_alerts - Alerte stoc

Concluzii

CaS oferă o soluție completă și modernă pentru managementul serviciilor de curățenie, cu accent pe:

  • Experiență utilizator optimizată
